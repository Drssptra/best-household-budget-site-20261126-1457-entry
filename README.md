Hearth & Ledger — a household budget site that runs entirely offline in the browser. One family, one month, everything in view: income and spending totals, a spending-by-category donut, monthly budgets with progress bars and over-budget warnings, a full transaction ledger with search, filters, add/edit/delete, six-month income-vs-spending insights, and savings goals with a monthly surplus tracker. All data is saved in the browser's local storage; the site ships with a realistic sample household so every page works on first open.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. No build step, no network requests — the site is plain static files under `app/`.
